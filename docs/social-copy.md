## 朋友圈版

参加了个麦当劳的开发者大赛，写了个小工具，想请大家帮忙点个赞。

事情的起点是我爸的体检报告。血压偏高，医生嘱咐少吃盐。后来陪他吃麦当劳，我顺手查了一下，巨无霸一个的钠含量是961毫克。医生给他定的每日钠限额是1500毫克。一个汉堡，64%的额度没了。这些东西菜单上不会写，网页上藏在很深的地方，单位还是千焦。

我就想，这事不该让人拿着计算器吃快餐。正好麦当劳开放了官方的数据接口，能查到全部一百多种餐品的营养数据，还能查门店、算价格、领券。我把它做成了一个助手，你把体检报告发给它，它自己读出血压血糖血脂的问题，然后告诉你这份菜单里哪些你能放心吃，哪些碰都别碰。推荐结果长这样，巨无霸占你钠限额的64%，红色，避开。麦香鱼加苹果片加红茶，钠只占37%，绿色，这顿放心。

全程只做一件事，把官方营养数据翻译成“对你说意味着什么”。它不给你医疗建议，饮食方案还是听医生的。但它能让你在柜台前站着的三十秒里，知道自己该点哪个。

比赛按仓库点赞数排名。如果你觉得这东西对家里有高血压、糖尿病的人有点用，去 GitHub 给我点个 Star，就当是替我爸点的一份麦香鱼。仓库地址在评论区，点开右上角一颗星就行，谢谢各位。

## 小红书版

标题：我把爸的体检报告喂给了AI，它说巨无霸不能点

正文：

家里老人有高血压的，先别划走，这条跟你有关。

事情是我爸体检完，血压偏高，医生说少吃盐。上周陪他去麦当劳，我随手查了一下营养表，当场愣住。巨无霸一个，钠961毫克。医生给他定的每日限量是1500毫克。也就是说一个汉堡下去，今天64%的盐额度已经用完了。麦辣鸡腿堡更狠，钠1208毫克，占81%。这些数字菜单上根本不显示，官方营养表藏在官网最深处，单位还是千焦，换算都要自己按计算器。

我本身是程序员，正好赶上麦当劳办开发者大赛，官方开放了数据接口，能查全部餐品的营养、门店、价格和优惠券。我就用几个晚上的时间做了个AI助手，专门干一件事，把体检报告变成点餐建议。

用法很简单。把体检报告拍照发给它，它自己读出血压多少、血糖多少，然后生成一份健康档案。之后每次吃麦当劳，它直接告诉你这顿怎么点。亲测给我爸的档案推的组合是麦香鱼加苹果片加红茶，钠占37%，全绿，36块5。页面直接给了三个颜色的条，绿的是放心吃，黄的是注意搭配，红的是今天别碰。它还会提醒把可乐换成无糖可乐，就这一下换掉35克碳水。

说几个实测里挺震惊的发现。

巨无霸对高血压人群是红色预警，一个就吃掉64%的盐额度。安格斯双层芝士堡更夸张，能量1003大卡，钠1373毫克，占92%，基本等于把一天的盐一顿吃完。反而麦香鱼、汉堡包这些看着平平无奇的，是钠最低的选择。点餐这件事，会看数据才吃得明白。

要说明的是，它只做营养数据的翻译，不做医疗建议，吃什么还是遵医嘱。但它解决的是另一个真实问题，站在柜台前的三十秒里，你到底该点哪个。

这个项目在参加麦当劳的比赛，名次按GitHub的Star数排。如果你觉得家里长辈用得上，或者单纯觉得这事挺有意思，去给我点个Star吧，仓库链接放在评论区置顶。手机就能操作，点一下星星图标就行。
